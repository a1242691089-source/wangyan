私隱政策

政策版本：3 · 生效日期：2026年6月29日 · 最近更新：2026年10月1日

一、前言

忘言（以下稱「本應用程式」）是一款開放源碼、本機優先的電子書閱讀器。我們深知私隱對您的重要性，本政策說明本應用程式如何處理資料，以及哪些選用功能會把資料傳送到您選擇或確認的網絡服務。

本應用程式不提供任何書籍內容，也不提供、內建、匯入或分享線上書源與訂閱來源，不進行線上搜尋或內容下載。TXT 目錄規則（包括選用的第三方相容規則）僅用於解析您本機或已授權的 TXT 檔案，規則中可能夾帶的腳本淨化程式碼不會被執行。

核心原則：閱讀、書庫、進度、筆記與大多數設定預設儲存在本機。只有在您主動設定或啟用 WebDAV 同步、MinerU 雲端解析、第三方 TTS、AI 翻譯等網絡功能時，相應的書籍檔案、閱讀資料或選取文字才會傳送到對應服務。按需下載的本機詞典安裝後離線查詢；查詢詞、書籍正文與過濾命中紀錄不會上載。

本機詞典正文不內建於 APK。您可以在設定中查看目錄後主動確認下載；下載檔會認證版本與 SHA-256，安裝後儲存在應用程式專用目錄，不進入系統備份或 WebDAV 同步。

開源透明：忘言 原創程式碼以 GNU GPLv3 授權條款發布，第三方元件遵循各自的授權條款，完整原始碼公開可供檢視。

3.2 會發生網絡傳輸的情境

  • 更新、公告、條款／政策版本檢查：應用程式可能存取項目發布頁或文件位址，並在您選擇仿宋字體時從 GitHub Raw 或 jsDelivr 按需下載字體檔。
  • WebDAV 同步：當您設定並手動或自動同步時，應用程式會連接您填寫的 WebDAV 伺服器，上載／下載書籍檔案、書籍清單（如檔名、雜湊、大小、修改時間）以及閱讀進度、書籤、筆記與筆記對應的選取文字。
  • MinerU 雲端解析：當您主動選擇雲端解析 PDF 時，所選 PDF、隨機化檔名、網絡 IP、解析參數、任務識別碼以及精準解析所需的個人 Token 會傳送至 MinerU／OpenDataLab 相關服務，並下載解析結果。
  • 第三方 TTS：當您選擇 OpenAI TTS、Xiaomi MiMo 或自訂相容服務時，當前朗讀文字段、模型／音色、風格提示與必要認證資訊會傳送至您設定的第三方服務，伺服器端如何處理資料取決於該服務的條款與政策。若您開啟 HTTP 連接，API Key 與朗讀文字可能未經加密傳輸而被竊聽。
  • AI 翻譯：當您啟用或手動觸發 AI 翻譯時，當前選取的文字、目標語言、模型參數與必要認證資訊會傳送至您選擇的 Xiaomi MiMo、DeepSeek、OpenAI 或自訂相容服務。若您主動允許 HTTP 連接，API Key 與選取文字可能未經加密傳輸而被竊聽。
  • 封面搜尋：當您進入網絡封面搜尋或提交搜尋時，當前書名與搜尋關鍵字會透過 WebView 傳送至您選擇的 Bing、百度或 Google 等搜尋服務；這些服務也可能記錄 IP、請求時間與瀏覽器網絡資訊。
  • 贊助頁貢獻者：當您開啟贊助／貢獻者頁面，應用程式會請求 GitHub contributors API 並載入 GitHub 頭像。GitHub 及其 CDN 會依自身政策接收網絡請求中介資料。
  • 外部連結：當您主動點擊 GitHub、意見反映、下載、第三方協議等連結時，會跳轉到對應網站。
  • 本機詞典下載：僅在您確認下載或更新時從固定 Release 位址下載並認證詞庫包；安裝後的查詢不上載查詢詞、書籍正文或過濾命中紀錄。
  • 摘錄卡片分享：卡片在裝置本機產生。只有當您點擊分享並選擇接收應用程式後，產生的圖片才會交給該應用程式，後續處理受接收應用程式的條款與私隱政策約束。

3.3 本應用程式不處理的資料

  • 不蒐集您的姓名、手機號碼、通訊錄、精確位置等個人身分資訊。
  • 不蒐集 IMEI、Android ID、MAC 位址等裝置識別碼用於追蹤。
  • 不整合第三方分析、廣告、用戶輪廓、第三方推播或當機回報 SDK。
  • 不提供 忘言 帳號系統或開發者營運的雲端書庫；WebDAV 是您自選伺服器，資料由您自行控制。
  • 除上述由您主動設定、啟用、進入或點擊的網絡功能外，不會主動上載您的書籍與閱讀內容。

四、資料儲存與安全

  • 閱讀資料庫與設定儲存在應用程式私有沙盒中，受 Android 應用程式隔離機制保護。
  • MinerU Token、WebDAV 密碼、第三方 TTS 與 AI 翻譯 API Key 以 Android Keystore 加密保存，並已從系統備份／裝置移轉規則中排除。
  • EPUB 閱讀 WebView 會阻擋外部網絡資源載入，出版方 CSS 僅用於本機排版顯示。
  • 暫存上載、下載與解析快取會在任務結束或快取清理時刪除；第三方 TTS 音訊快取可自動淘汰。
  • 您可以在應用程式內清除閱讀歷史、書籤、快取與相關設定；解除安裝會刪除應用程式私有資料，但不會自動刪除您裝置上自行管理的原始電子書檔案。

五、第三方服務與用戶自選服務

本應用程式不整合分析、廣告、第三方推播或當機報告服務。以下網絡能力均為選用或由用戶觸發：

  • OpenDataLab / MinerU：用於雲端 PDF 解析，獨立於 忘言 營運，使用前請閱讀其服務協議與個人資訊保護政策。
  • WebDAV 服務商或自建伺服器：用於同步書籍與閱讀資料。伺服器位址、可用性、安全性、資料保存與刪除由您選擇的服務方或自建環境決定。
  • 第三方 TTS 服務：包括 OpenAI TTS、Xiaomi MiMo 或您設定的相容介面。朗讀文字、風格提示、API Key 使用與費用規則受對應服務條款約束。
  • AI 翻譯服務：包括 Xiaomi MiMo、DeepSeek、OpenAI 或您設定的相容介面。選取文字、目標語言、模型參數、API Key 使用與費用規則受對應服務條款約束。
  • GitHub 及其 CDN：用於更新、貢獻者清單、頭像與遠端字體下載。GitHub 及 CDN 的網絡日誌、保存與刪除規則由其自身政策決定。
  • Bing、百度、Google 等搜尋服務：僅在您主動使用網絡封面搜尋時接收書名或搜尋關鍵字，具體處理由對應服務政策決定。
  • 詞典發布位址：詞庫 Release 與目錄託管於項目設定的 GitHub 位址；下載完成後，詞典正文與查詢不依賴網絡。

如不希望書籍或文字離開裝置，請不要啟用 WebDAV 同步、MinerU 雲端解析、第三方 TTS、AI 翻譯或網絡封面搜尋，並使用本機閱讀、本機解析、系統 TTS 與本機詞典。

六、兒童私隱

本應用程式並非針對 13 歲以下兒童，不會故意蒐集兒童個人資訊。監護人如發現兒童可能透過選用第三方服務提交了個人資訊，請聯絡我們並同時聯絡相應服務方。

七、私隱政策的變更

我們可能因功能、法令法規或第三方服務變化更新本政策。更新後將在應用程式內或網頁公布，並更新「最近更新」日期；重大變更會透過應用程式內版本提示要求您重新閱讀並確認。
