プライバシーポリシー

ポリシーバージョン：3 · 施行日：2026年6月29日 · 最終更新日：2026年10月1日

一、はじめに

忘言（「本アプリ」）は、オープンソースでローカル優先の電子書籍リーダーです。プライバシーが重要であることは承知しています。本ポリシーは、本アプリがデータをどう扱うか、またどの任意機能が、利用者が選択または確認したネットワークサービスへデータを送信するかを説明します。

本アプリは書籍コンテンツを提供せず、オンラインの書源・購読フィードの提供、組み込み、インポート、共有も行いません。オンライン検索やコンテンツのダウンロードも行いません。TXT の目次ルール（任意のサードパーティ互換ルールを含む）は、端末内または利用者が許可した TXT ファイルの解析にのみ使われ、ルールに含まれるスクリプト浄化コードが実行されることはありません。

基本方針：閲覧、書庫、進捗、ノートおよびほとんどの設定は、既定で本機に保存されます。WebDAV 同期、MinerU クラウド解析、サードパーティ TTS、AI 翻訳などのネットワーク機能を利用者が自ら設定・有効化したときに限り、該当する書籍ファイル、閲覧データ、選択テキストが対応サービスへ送信されます。オンデマンドのローカル辞書はインストール後オフラインで検索され、検索語、本文、フィルター一致記録はアップロードされません。

ローカル辞書の本文は APK に組み込まれていません。設定でカタログを確認したうえでダウンロードを確定できます。パッケージはバージョンと SHA-256 を検証し、アプリ専用ディレクトリに保存され、システムバックアップや WebDAV 同期の対象外です。

オープンソースの透明性：忘言 のオリジナルコードは GNU GPLv3 で公開され、サードパーティコンポーネントは各ライセンスに従います。完全なソースコードは公開され、誰でも検証できます。

二、権限

本アプリは、閲覧と任意機能に必要な Android 権限のみを要求します。

  • ✕ 位置情報
  • ✕ カメラ / マイク
  • ✕ 連絡先
  • ✕ 電話の状態
  • ✕ SMS、カレンダーなど閲覧と無関係な機微な権限

3.2 ネットワーク送信が発生する場面

  • 更新・お知らせ・規約やポリシーの確認：プロジェクトのリリースページや文書アドレスにアクセスする場合があり、仿宋フォントを選択したときは GitHub Raw または jsDelivr から必要に応じてフォントファイルをダウンロードします。
  • WebDAV 同期：利用者が設定して手動または自動で同期すると、入力した WebDAV サーバーへ接続し、書籍ファイル、書籍マニフェスト（ファイル名、ハッシュ、サイズ、更新日時など）、読書進捗、ブックマーク、ノートおよびノートに対応する選択テキストを送受信します。
  • MinerU クラウド解析：PDF のクラウド解析を利用者が明示的に選ぶと、選択した PDF、ランダム化したファイル名、ネットワーク IP、解析パラメータ、タスク識別子、および高精度解析に必要な個人トークンが MinerU/OpenDataLab の関連サービスへ送信され、解析結果をダウンロードします。
  • サードパーティ TTS：OpenAI TTS、Xiaomi MiMo、または互換サービスを選ぶと、現在の朗読テキスト、モデル/音色、スタイル指示、必要な認証情報が設定したサービスへ送信されます。サーバー側の扱いは各サービスの規約とポリシーによります。HTTP を有効にすると、API キーと朗読テキストが暗号化されずに送信され、傍受される可能性があります。
  • AI 翻訳：AI 翻訳を有効化または手動で実行すると、現在選択しているテキスト、翻訳先の言語、モデルパラメータ、必要な認証情報が、選択した Xiaomi MiMo、DeepSeek、OpenAI または互換サービスへ送信されます。HTTP を許可すると、API キーと選択テキストが暗号化されずに送信され、傍受される可能性があります。
  • 表紙検索：ネットワーク表紙検索を開く、または検索を送信すると、現在の書名と検索語が WebView 経由で Bing、百度、Google などの選択した検索サービスへ送信されます。これらのサービスは IP、リクエスト時刻、ブラウザーやネットワークの情報を記録する場合があります。
  • スポンサーページのコントリビューター：スポンサー/コントリビューターのページを開くと、GitHub contributors API を要求し、GitHub のアバターを読み込みます。GitHub とその CDN は通常のリクエストメタデータを各社のポリシーに従って受け取ります。
  • 外部リンク：GitHub、フィードバック、ダウンロード、サードパーティ規約などのリンクを利用者がタップしたときに対応するサイトを開きます。
  • ローカル辞書のダウンロード：利用者がダウンロードまたは更新を確定したときにのみ、固定の Release アドレスから辞書パッケージを取得して検証します。インストール後の検索では、検索語、本文、フィルター一致記録をアップロードしません。
  • 抜粋カードの共有：カードは端末内で生成されます。利用者が共有をタップして受け取り先のアプリを選んだときに限り、生成した画像がそのアプリへ渡され、以降の扱いは受け取り側の規約とプライバシーポリシーに従います。

3.3 本アプリが扱わないデータ

  • 氏名、電話番号、連絡先、正確な位置などの個人を特定する情報を収集しません。
  • IMEI、Android ID、MAC アドレスなどの端末識別子を追跡目的で収集しません。
  • サードパーティの分析、広告、プロファイリング、プッシュ通知、クラッシュ報告 SDK を組み込みません。
  • 忘言 アカウントや開発者が運営するクラウド書庫は提供しません。WebDAV は利用者が選ぶサーバーであり、データは利用者が管理します。
  • 利用者が自ら設定・有効化・表示・タップした上記のネットワーク機能を除き、書籍や閲覧内容を自発的にアップロードしません。

四、保存とセキュリティ

  • 読書データベースと設定はアプリ専用のサンドボックスに保存され、Android のアプリ分離機構で保護されます。
  • MinerU トークン、WebDAV パスワード、サードパーティ TTS と AI 翻訳の API キーは Android Keystore で暗号化して保存し、システムバックアップと端末移行の対象から除外しています。
  • EPUB 閲覧用の WebView は外部ネットワークリソースの読み込みを遮断し、出版社の CSS はローカルな組版表示にのみ使います。
  • 一時的なアップロード、ダウンロード、解析のキャッシュは、タスク終了時またはキャッシュ削除時に消去されます。サードパーティ TTS の音声キャッシュは自動的に破棄される場合があります。
  • 読書履歴、ブックマーク、キャッシュ、関連設定はアプリ内で消去できます。アンインストールするとアプリ専用データは削除されますが、端末上で利用者が管理する元の電子書籍ファイルは削除されません。

五、サードパーティサービスと利用者が選ぶサービス

本アプリは分析、広告、プッシュ通知、クラッシュ報告のサービスを組み込んでいません。以下のネットワーク機能はいずれも任意、または利用者の操作で実行されます。

  • OpenDataLab / MinerU：PDF のクラウド解析に使用し、忘言 とは独立して運営されています。利用前にサービス規約と個人情報保護方針をお読みください。
  • WebDAV サービス事業者または自前サーバー：書籍と読書データの同期に使用します。アドレス、可用性、安全性、保存、削除は、利用者が選んだ事業者または自前の環境により決まります。
  • サードパーティ TTS サービス：OpenAI TTS、Xiaomi MiMo、または設定した互換インターフェースを含みます。朗読テキスト、スタイル指示、API キーの使用、料金は各サービスの規約に従います。
  • AI 翻訳サービス：Xiaomi MiMo、DeepSeek、OpenAI、または設定した互換インターフェースを含みます。選択テキスト、翻訳先の言語、モデルパラメータ、API キーの使用、料金は各サービスの規約に従います。
  • GitHub とその CDN：更新、コントリビューター一覧、アバター、リモートフォントの取得に使用します。ネットワークログの記録・保存・削除は GitHub と CDN 各社のポリシーによります。
  • Bing、百度、Google などの検索サービス：利用者がネットワーク表紙検索を自ら使ったときに限り、書名や検索語を受け取ります。取り扱いは各サービスのポリシーによります。
  • 辞書の配布アドレス：辞書の Release とカタログはプロジェクトが設定した GitHub アドレスでホストされます。ダウンロード後は、辞書本文と検索にネットワークを必要としません。

書籍やテキストを端末外に出したくない場合は、WebDAV 同期、MinerU クラウド解析、サードパーティ TTS、AI 翻訳、ネットワーク表紙検索を有効にせず、ローカル閲覧、ローカル解析、システム TTS、ローカル辞書をご利用ください。

六、児童のプライバシー

本アプリは 13 歳未満の児童を対象としておらず、児童の個人情報を故意に収集しません。保護者の方が、児童が任意のサードパーティサービスを通じて個人情報を送信した可能性に気づいた場合は、当方および該当サービス事業者へご連絡ください。

七、本ポリシーの変更

機能、法令、サードパーティサービスの変化に応じて本ポリシーを更新する場合があります。更新後はアプリ内またはウェブで公表し、「最終更新日」を更新します。重要な変更は、アプリ内のバージョン通知で再読と確認をお願いします。

九、適用範囲

本プライバシーポリシーは Android 上の 忘言（com.wangyan.reader）の機能にのみ適用され、サードパーティサービス自身のデータ処理には適用されません。
