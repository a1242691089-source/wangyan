1. 들어가며

忘言(이하 “본 앱”)는 오픈소스 로컬 우선 전자책 리더입니다. 개인정보가 중요하다는 점을 잘 알고 있습니다. 본 방침은 본 앱이 데이터를 어떻게 처리하는지, 그리고 어떤 선택 기능이 이용자가 선택하거나 확인한 네트워크 서비스로 데이터를 보내는지 설명합니다.

본 앱은 어떤 도서 콘텐츠도 제공하지 않으며, 온라인 서원이나 구독 피드를 제공·내장·가져오기·공유하지 않습니다. 온라인 검색이나 콘텐츠 다운로드도 하지 않습니다. TXT 목차 규칙(선택적 서드파티 호환 규칙 포함)은 기기 내 파일이나 이용자가 권한을 부여한 TXT 파일을 해석하는 데에만 사용되며, 규칙에 포함된 스크립트 정화 코드는 실행되지 않습니다.

핵심 원칙: 읽기, 서재, 진행률, 노트 및 대부분의 설정은 기본적으로 기기에 저장됩니다. WebDAV 동기화, MinerU 클라우드 해석, 서드파티 TTS, AI 번역 등 네트워크 기능을 이용자가 직접 설정하거나 활성화할 때에만 해당 도서 파일, 읽기 데이터 또는 선택한 텍스트가 해당 서비스로 전송됩니다. 필요할 때 받는 로컬 사전은 설치 후 오프라인으로 검색되며, 검색어와 본문, 필터 적중 기록은 업로드되지 않습니다.

로컬 사전 본문은 APK에 포함되어 있지 않습니다. 설정에서 목록을 확인한 뒤 다운로드를 확정할 수 있으며, 패키지는 버전과 SHA-256을 검증하고 앱 전용 디렉터리에 저장되며 시스템 백업과 WebDAV 동기화에서 제외됩니다.

오픈소스 투명성: 忘言의 자체 코드는 GNU GPLv3로 공개되며, 서드파티 구성 요소는 각자의 라이선스를 따릅니다. 전체 소스 코드는 공개되어 누구나 검토할 수 있습니다.

3.2 네트워크 전송이 발생하는 상황

  • 업데이트·공지·약관 및 방침 확인: 프로젝트 릴리스 페이지나 문서 주소에 접속할 수 있으며, 방송체(仿宋) 글꼴을 선택하면 GitHub Raw 또는 jsDelivr에서 필요할 때 글꼴 파일을 내려받습니다.
  • WebDAV 동기화: 이용자가 설정하고 수동 또는 자동으로 동기화하면 입력한 WebDAV 서버에 접속하여 도서 파일, 도서 목록(파일 이름, 해시, 크기, 수정 시각 등), 읽기 진행률, 북마크, 노트 및 노트에 연결된 선택 텍스트를 주고받습니다.
  • MinerU 클라우드 해석: PDF 클라우드 해석을 이용자가 직접 선택하면 선택한 PDF, 무작위화한 파일 이름, 네트워크 IP, 해석 매개변수, 작업 식별자, 정밀 해석에 필요한 개인 토큰이 MinerU/OpenDataLab 관련 서비스로 전송되고 결과를 내려받습니다.
  • 서드파티 TTS: OpenAI TTS, Xiaomi MiMo 또는 호환 서비스를 선택하면 현재 낭독 텍스트, 모델/음색, 스타일 지시, 필요한 인증 정보가 설정한 서비스로 전송됩니다. 서버의 처리 방식은 해당 서비스의 약관과 방침을 따릅니다. HTTP를 켜면 API 키와 낭독 텍스트가 암호화되지 않은 채 전송되어 도청될 수 있습니다.
  • AI 번역: AI 번역을 활성화하거나 직접 실행하면 현재 선택한 텍스트, 대상 언어, 모델 매개변수, 필요한 인증 정보가 선택한 Xiaomi MiMo, DeepSeek, OpenAI 또는 호환 서비스로 전송됩니다. HTTP를 허용하면 API 키와 선택 텍스트가 암호화되지 않은 채 전송되어 도청될 수 있습니다.
  • 표지 검색: 온라인 표지 검색을 열거나 검색을 제출하면 현재 책 제목과 검색어가 WebView를 통해 이용자가 선택한 Bing, 바이두, Google 등 검색 서비스로 전송됩니다. 이러한 서비스는 IP, 요청 시각, 브라우저 및 네트워크 정보를 기록할 수 있습니다.
  • 후원 페이지 기여자: 후원/기여자 페이지를 열면 GitHub contributors API를 요청하고 GitHub 아바타를 불러옵니다. GitHub와 그 CDN은 각자의 방침에 따라 일반적인 요청 메타데이터를 받습니다.
  • 외부 링크: GitHub, 피드백, 다운로드, 서드파티 약관 등의 링크를 눌렀을 때 해당 사이트로 이동합니다.
  • 로컬 사전 다운로드: 이용자가 다운로드나 업데이트를 확정했을 때에만 고정된 Release 주소에서 사전 패키지를 받아 검증합니다. 설치 후 검색은 검색어, 본문, 필터 적중 기록을 업로드하지 않습니다.
  • 발췌 카드 공유: 카드는 기기에서 생성됩니다. 이용자가 공유를 눌러 받을 앱을 선택한 때에만 생성된 이미지가 해당 앱으로 전달되며, 이후 처리는 받는 앱의 약관과 개인정보 처리방침을 따릅니다.

3.3 본 앱이 처리하지 않는 데이터

  • 이름, 전화번호, 연락처, 정확한 위치 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.
  • IMEI, Android ID, MAC 주소 등 기기 식별자를 추적 목적으로 수집하지 않습니다.
  • 서드파티 분석, 광고, 프로파일링, 푸시 알림, 충돌 보고 SDK를 포함하지 않습니다.
  • 忘言 계정 시스템이나 개발자가 운영하는 클라우드 서재를 제공하지 않습니다. WebDAV는 이용자가 선택한 서버이며 데이터는 이용자가 관리합니다.
  • 이용자가 직접 설정·활성화·열람·클릭한 위의 네트워크 기능 외에는 도서와 읽기 내용을 자발적으로 업로드하지 않습니다.

4. 저장과 보안

  • 읽기 데이터베이스와 설정은 앱 전용 샌드박스에 저장되며 Android 앱 격리 메커니즘으로 보호됩니다.
  • MinerU 토큰, WebDAV 비밀번호, 서드파티 TTS와 AI 번역 API 키는 Android Keystore로 암호화해 저장하며 시스템 백업과 기기 이전 대상에서 제외합니다.
  • EPUB 읽기용 WebView는 외부 네트워크 리소스 로드를 차단하며, 출판사 CSS는 로컬 조판 표시에만 사용합니다.
  • 임시 업로드, 다운로드, 해석 캐시는 작업 종료 또는 캐시 정리 시 삭제되며, 서드파티 TTS 오디오 캐시는 자동으로 정리될 수 있습니다.
  • 읽기 기록, 북마크, 캐시, 관련 설정은 앱 안에서 삭제할 수 있습니다. 앱을 삭제하면 앱 전용 데이터는 지워지지만, 기기에서 이용자가 직접 관리하는 원본 전자책 파일은 삭제되지 않습니다.

5. 서드파티 서비스와 이용자가 선택한 서비스

본 앱은 분석, 광고, 푸시 알림, 충돌 보고 서비스를 포함하지 않습니다. 다음 네트워크 기능은 모두 선택 사항이거나 이용자의 조작으로 실행됩니다.

  • OpenDataLab / MinerU: PDF 클라우드 해석에 사용하며 忘言와 독립적으로 운영됩니다. 사용 전에 서비스 약관과 개인정보 보호정책을 읽어 주세요.
  • WebDAV 제공자 또는 직접 구축한 서버: 도서와 읽기 데이터 동기화에 사용합니다. 주소, 가용성, 보안, 보관, 삭제는 이용자가 선택한 제공자나 직접 구축한 환경이 결정합니다.
  • 서드파티 TTS 서비스: OpenAI TTS, Xiaomi MiMo 또는 설정한 호환 엔드포인트를 포함합니다. 낭독 텍스트, 스타일 지시, API 키 사용, 요금은 해당 서비스 약관을 따릅니다.
  • AI 번역 서비스: Xiaomi MiMo, DeepSeek, OpenAI 또는 설정한 호환 엔드포인트를 포함합니다. 선택 텍스트, 대상 언어, 모델 매개변수, API 키 사용, 요금은 해당 서비스 약관을 따릅니다.
  • GitHub와 그 CDN: 업데이트, 기여자 목록, 아바타, 원격 글꼴 다운로드에 사용합니다. 네트워크 로그의 기록·보관·삭제는 GitHub와 CDN 각자의 방침을 따릅니다.
  • Bing, 바이두, Google 등 검색 서비스: 이용자가 온라인 표지 검색을 직접 사용할 때에만 책 제목이나 검색어를 받습니다. 처리는 각 서비스의 방침을 따릅니다.
  • 사전 배포 주소: 사전 Release와 목록은 프로젝트가 설정한 GitHub 주소에 호스팅됩니다. 다운로드가 끝나면 사전 본문과 검색에 네트워크가 필요하지 않습니다.
