使用者條款

條款版本：2 · 生效日期：2026年6月29日 · 最近更新：2026年10月1日

一、條款的接受

歡迎使用 忘言（以下稱「本應用程式」）。下載、安裝、開啟或使用本應用程式，即表示您已閱讀、理解並同意受本使用者條款約束；如不同意，請停止使用本應用程式。

二、應用程式說明

2.1 應用程式功能

忘言 是一款開放原始碼、本機優先的電子書閱讀器，主要功能包括：

  • 閱讀 EPUB、TXT、PDF 格式電子書，管理本機書庫、閱讀進度、書籤、筆記與閱讀統計。
  • 透過系統檔案選擇器匯入檔案或授權資料夾，以便直接讀取您指定位置的書籍。
  • 在應用程式內編輯 TXT，並在您確認儲存時寫回您授權的檔案。
  • 提供系統 TTS 聽書；也可由您主動設定 OpenAI TTS、Xiaomi MiMo 或自訂相容第三方 TTS 服務。
  • 在您主動啟用後，透過 MinerU/OpenDataLab 雲端服務解析 PDF。
  • 在您主動設定後，透過 WebDAV 同步書籍、閱讀進度、書籤與筆記。
  • 在您主動設定並啟用或手動觸發後，透過 Xiaomi MiMo、DeepSeek、OpenAI 或自訂相容服務翻譯選取的文字。
  • 在「設定 → 服務 → 本機詞典」中按需下載詞庫；安裝後離線查詢，不會自動下載或更新。
  • 將選取文字、筆記或書籤製作成摘錄卡片，並由您選擇儲存到系統相片庫或分享給其他應用程式。
  • 在您主動使用時，透過 Bing、百度或 Google 等搜尋服務尋找網路封面；在您選擇仿宋字型時按需下載遠端字型。

2.2 應用程式性質

  • 本機閱讀、本機解析與系統 TTS 預設不上傳書籍內容。
  • WebDAV、MinerU 雲端解析、第三方 TTS 與 AI 翻譯均為選用網路功能，需您主動設定、啟用或確認。
  • 本應用程式不提供 忘言 帳號註冊、登入或開發者營運的雲端書庫。
  • 本機詞典查詢在裝置上完成，不上傳查詢詞、書籍正文或過濾命中紀錄。
  • 忘言 原創程式碼以 GNU GPLv3 授權條款發布，第三方元件及改作程式碼遵循各自的授權條款。

七、第三方服務與使用者自選服務

  • MinerU/OpenDataLab：用於雲端 PDF 解析。首次啟用前，您需要閱讀並同意 OpenDataLab 的服務協議與個人資訊保護政策，並確認檔案上傳。
  • WebDAV：由您填寫伺服器資訊並決定手動或自動同步。同步資料可能包括電子書檔案、書籍清單、閱讀進度、書籤、筆記與選取文字。
  • 第三方 TTS：由您選擇服務、填寫 Base URL／API Key 並確認風險。朗讀文字段與風格提示會傳送到相應服務。
  • AI 翻譯：由您選擇服務、填寫 Base URL／API Key 並啟用或手動觸發。當前選取文字、目標語言與模型參數會傳送到相應服務；開啟 HTTP 時可能發生明文傳輸。
  • GitHub 及其 CDN：用於更新、貢獻者清單、頭像與遠端字型下載；其網路日誌與資料處理遵循 GitHub 及 CDN 自身政策。
  • 封面搜尋服務：僅在您主動使用網路封面搜尋時接收書名或搜尋關鍵字，具體處理遵循 Bing、百度或 Google 等服務的政策。
  • 贊助／貢獻者頁面：開啟頁面時會請求 GitHub contributors API 並載入頭像，GitHub 及其 CDN 會接收正常網路請求中介資料。
  • 詞典下載：只有您在設定中確認下載或更新時，應用程式才會從設定的 GitHub Release 下載詞庫包；安裝後的查詢不呼叫線上詞典服務。
