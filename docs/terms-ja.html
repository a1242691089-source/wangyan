一、本規約への同意

忘言（「本アプリ」）をご利用いただきありがとうございます。本アプリをダウンロード、インストール、起動または利用した時点で、本規約を読み、理解し、これに拘束されることに同意したものとみなされます。同意いただけない場合は本アプリの利用を中止してください。

二、本アプリについて

2.1 機能

忘言 はオープンソースでローカル優先の電子書籍リーダーです。主な機能は次のとおりです。

  • EPUB、TXT、PDF 形式の電子書籍を読み、ローカル書庫、読書進捗、ブックマーク、ノート、読書統計を管理します。
  • システムのファイル選択画面からファイルをインポートしたりフォルダを許可したりして、指定した場所の書籍を直接読み取ります。
  • アプリ内で TXT を編集し、保存を確定したときに許可されたファイルへ書き戻します。
  • システム TTS による読み上げ。OpenAI TTS、Xiaomi MiMo、または互換性のあるサードパーティ TTS を利用者が任意に設定することもできます。
  • 利用者が有効化したうえで、MinerU/OpenDataLab のクラウドサービスで PDF を解析します。
  • 利用者が設定したうえで、WebDAV 経由で書籍、読書進捗、ブックマーク、ノートを同期します。
  • 利用者が設定し、有効化または手動で実行したときに、Xiaomi MiMo、DeepSeek、OpenAI または互換サービスで選択テキストを翻訳します。
  • 「設定 → サービス → ローカル辞書」から辞書データを必要に応じてダウンロードします。インストール後はオフラインで検索でき、自動でダウンロードや更新は行いません。
  • 選択したテキスト、ノート、ブックマークから抜粋カードを作成し、利用者の選択でシステムの写真ライブラリへ保存したり他のアプリへ共有したりします。
  • 利用者が利用したときに、Bing、百度、Google などの検索サービスでネットワーク上の表紙を探し、仿宋フォントを選んだときはリモートフォントを必要に応じてダウンロードします。

2.2 本アプリの性質

  • ローカル閲覧、ローカル解析、システム TTS は、既定では書籍の内容をアップロードしません。
  • WebDAV、MinerU クラウド解析、サードパーティ TTS、AI 翻訳はいずれも任意のネットワーク機能であり、利用者による設定・有効化・確認が必要です。
  • 本アプリは 忘言 アカウントの登録・ログインや、開発者が運営するクラウド書庫を提供しません。
  • ローカル辞書の検索は端末内で完結し、検索語、書籍本文、フィルター一致記録をアップロードしません。
  • 忘言 のオリジナルコードは GNU GPLv3 で公開され、サードパーティコンポーネントおよび改変コードは各ライセンスに従います。

利用者の権利

  • いつでも本アプリをアンインストールできます。アンインストールするとアプリ専用データは削除されますが、利用者が自ら管理する元の電子書籍ファイルは削除されません。
  • オープンソースライセンスに従う限り、本アプリのソースコードを閲覧、変更、配布できます。

利用者の義務

  • 本アプリを利用して、違法行為、権利侵害、ネットワークサービスの安全を損なう行為を行わないでください。

六、プライバシー保護

本アプリはプライバシーを重視します。読書データは既定で本機に保存されます。ネットワーク表紙検索、コントリビューター／アバターの表示、リモートフォントのダウンロード、辞書パッケージのダウンロード、更新確認、および利用者が設定・有効化した WebDAV 同期、MinerU クラウド解析、サードパーティ TTS、AI 翻訳、外部リンクへのアクセスでは、それぞれネットワーク要求が発生します。インストール済み辞書の検索と抜粋カードの生成は端末内で完結し、利用者が自ら共有したときに限り画像が受け取り先アプリへ渡されます。詳細はプライバシーポリシーをご覧ください。

七、サードパーティサービスと利用者が選ぶサービス

  • MinerU/OpenDataLab：PDF のクラウド解析に使用します。初回の有効化前に、OpenDataLab のサービス規約と個人情報保護方針を読み、同意したうえでファイルのアップロードを確認する必要があります。
  • WebDAV：利用者がサーバー情報を入力し、手動または自動の同期を決めます。同期されるデータには、電子書籍ファイル、書籍マニフェスト、読書進捗、ブックマーク、ノート、選択テキストが含まれる場合があります。
  • サードパーティ TTS：利用者がサービスを選び、Base URL／API キーを入力してリスクに同意します。朗読テキストとスタイル指示が対応サービスへ送信されます。
  • AI 翻訳：利用者がサービスを選び、Base URL／API キーを入力して有効化または手動実行します。現在の選択テキスト、翻訳先の言語、モデルパラメータが対応サービスへ送信されます。HTTP を有効にすると平文で送信される場合があります。
  • GitHub とその CDN：更新、コントリビューター一覧、アバター、リモートフォントの取得に使用します。ネットワークログとデータの取り扱いは GitHub と CDN 各社の方針に従います。
  • 表紙検索サービス：利用者がネットワーク表紙検索を自ら使ったときに限り、書名や検索語を受け取ります。取り扱いは Bing、百度、Google などの方針に従います。
  • スポンサー／コントリビューターのページ：ページを開くと GitHub contributors API を要求してアバターを読み込み、GitHub とその CDN が通常のリクエストメタデータを受け取ります。
  • 辞書のダウンロード：利用者が設定でダウンロードまたは更新を確定したときにのみ、設定された GitHub Release から辞書パッケージを取得します。インストール後の検索はオンライン辞書サービスを呼び出しません。
