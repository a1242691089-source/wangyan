一、接受協議
下載、安裝、開啟或使用忘言，即表示您已閱讀、理解並同意本協議。如不同意，請停止使用本應用程式。
二、應用程式功能
忘言是開源、本地優先的電子書閱讀器，支援 EPUB、TXT、PDF 閱讀、本地書架、閱讀進度、書籤、筆記、閱讀統計、系統 TTS、TXT 編輯、檔案/檔案夾授權讀取、可選 MinerU 雲端 PDF 解析、可選 WebDAV 同步、可選第三方 TTS，以及網路封面搜尋和按需遠端字型下載。
本應用程式不提供忘言帳號註冊、登入或開發者營運的雲端書庫。WebDAV、MinerU、第三方 TTS、網路封面搜尋和遠端字型下載均在您主動設定、啟用或使用時發生。
開啟贊助/貢獻者頁面時會請求 GitHub contributors API 並載入頭像，GitHub 及其 CDN 會接收正常網路請求中繼資料。
三、使用者權利與義務
• 您可以免費使用可用功能，自主管理閱讀資料、快取和設定，並隨時停用可選網路功能。

• 自行保管 WebDAV 密碼、MinerU Token 和第三方 TTS API Key，並遵守對應服務商協議、隱私政策、費用和限額規則。
