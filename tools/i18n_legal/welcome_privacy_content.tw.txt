一、核心原則
忘言是開源、本地優先的電子書閱讀器。閱讀、書架、進度、書籤、筆記和大部分設定預設保存在本機。網路封面搜尋、貢獻者/頭像展示、遠端字型下載、更新檢查，以及您主動設定或啟用的 WebDAV 同步、MinerU 雲端解析、第三方 TTS 或外部連結會產生相應網路請求。
二、權限用途
• READ_EXTERNAL_STORAGE（Android 12 及以下）：讀取您選擇的 EPUB、TXT、PDF 等電子書檔案。
• READ_MEDIA_IMAGES（Android 13 及以上）：讀取電子書封面、匯出圖片或您選擇的圖片資源。
• INTERNET / ACCESS_NETWORK_STATE：用於更新和政策版本檢查、遠端字型下載、WebDAV、MinerU、第三方 TTS、網路封面搜尋和外部頁面存取。
• WRITE_SETTINGS：僅在您啟用自訂亮屏時間時修改系統螢幕關閉時間。
• 前景服務和通知權限：用於 TTS 背景播放、PDF/MinerU 解析或 WebDAV 同步進度通知。
• WAKE_LOCK：在 TTS 背景播放期間保持裝置喚醒，避免播放意外中斷。
• SYSTEM_ALERT_WINDOW：僅在您啟用懸浮窗字幕時顯示跨應用程式懸浮字幕視窗。
本應用程式目前最低支援 Android 11，不會在受支援裝置上請求 Android 9 及以下的舊式寫入儲存權限；不申請位置、相機/麥克風、通訊錄、電話狀態、簡訊、日曆等與閱讀無關的敏感權限。
三、本機保存的資料
電子書檔案、閱讀進度、書籤、筆記及選取文字、閱讀時間、閱讀偏好、檔案/檔案夾授權 URI、TXT 編輯內容、MinerU 設定、WebDAV 設定、第三方 TTS 設定和本地 TTS 音訊快取可能保存在本地。MinerU Token、WebDAV 密碼、第三方 TTS API Key 使用 Android Keystore 加密保存，並排除系統備份/裝置遷移。
四、會傳輸資料的場景
• 更新、公告和條款/政策版本檢查：應用程式可能存取專案發佈頁或檔案位址。
• 遠端字型：當您選擇或恢復仿宋字型時，應用程式會從 GitHub Raw 或 jsDelivr 按需下載字型檔案，不上傳書籍內容。
• WebDAV 同步：向您設定的伺服器上傳/下載書籍檔案、書籍清單、閱讀進度、書籤、筆記和選取文字。
• MinerU 雲端解析：向 OpenDataLab/MinerU 傳送您選定的 PDF、解析參數、工作識別碼；精準解析還會使用您的個人 Token。
• 第三方 TTS：向您選擇的服務傳送目前朗讀文字段、模型/音色、風格提示和必要認證資訊。若開啟 HTTP 連線，API Key 和朗讀文字可能未經加密傳輸並被竊聽。
• 網路封面搜尋：向您選擇的 Bing、百度或 Google 等搜尋服務傳送書名和搜尋關鍵字；這些服務可能記錄 IP、請求時間和瀏覽器網路資訊。
• 贊助頁貢獻者：開啟貢獻者頁面時，應用程式會請求 GitHub contributors API 並載入 GitHub 頭像，GitHub 及其 CDN 會接收網路請求中繼資料。
• 外部連結：僅在您主動點擊 GitHub、回饋、下載或第三方協議連結時存取對應網站。
五、我們不會做什麼
本應用程式不收集姓名、手機號碼、通訊錄、精確位置或裝置識別碼用於追蹤；不整合分析、廣告、使用者輪廓、第三方推送或崩潰回報 SDK；不提供忘言帳號系統或開發者營運的雲端書庫。除上述由您主動設定、啟用、進入或點擊的網路功能外，不主動上傳您的書籍和閱讀內容。
六、第三方服務
OpenDataLab/MinerU、WebDAV 服務商、第三方 TTS、GitHub 及其 CDN、Bing、百度和 Google 等服務均獨立於忘言營運。其網路日誌、可用性、計費、資料保存、刪除和合規要求由對應服務條款和隱私政策決定。
七、資料管理
您可以在應用程式內清除閱讀歷史、快取和相關設定，或隨時解除安裝應用程式。解除安裝會刪除應用程式私有資料，但不會自動刪除您自行管理的原始電子書檔案、WebDAV 伺服器副本或第三方服務已處理的資料。
八、兒童私隱
本應用程式不針對 13 歲以下兒童，不會故意收集兒童個人資料。監護人如發現兒童可能透過可選第三方服務提交了個人資料，請聯絡我們並同時聯絡相應服務方。
九、政策變更、聯絡我們與適用範圍
我們可能因功能、法律法規或第三方服務變化更新本政策。重大變更會透過應用程式內版本提示要求您重新閱讀並確認。若您對本政策或資料處理有疑問，請聯絡開發者 https://github.com/a1242691089-source/wangyan/issues。本政策僅適用於忘言應用程式（com.wangyan.reader）在 Android 平台的功能，不適用於第三方服務自身的資料處理活動。
本隱私政策最後更新於 2026年10月1日。
十、本次更新補充說明
• Android 17 及以上只會在連線至您設定的 NAS 或區域網路 WebDAV 時按需申請本機網路權限，公網 WebDAV 不需要此權限。
• 啟用或手動觸發 AI 翻譯時，所選文字、目標語言、模型參數和驗證資料會傳送至您選擇的 Xiaomi MiMo、DeepSeek、OpenAI 或自訂相容服務；API Key 透過 Android Keystore 加密保存在本機。允許 HTTP 時可能以明文傳輸。
• 本機詞典只在確認後下載並離線查詢。摘錄卡片在本機產生，只有主動分享時才會交給您選擇的接收應用程式。
