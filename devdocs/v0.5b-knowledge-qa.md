## 三、方案硬约束（验收标准）

1. 回答必须带来源；推断显式标注〔推断〕；无证据直说「提供的片段没有直接讲到这一点」
2. 引用必须逐字用「」包裹；不下作者判断；结论标 `[n]`；跟随提问语言
3. `[n]` → citations JSON 落库 → 可点角标 → `Screen.Reader.createRoute(bookId, chapter, position)` 复用 V0.3a 证据跳转链路
4. 模型不守协议时**不做自动改写/重试**，靠 UI 提示条（已实现 `qa_uncited` 等）

## 四、实现结构

### 检索（无向量、无 FTS）
- `ai/qa/QaTokenizer`：ascii 词≥2 + 中文 2-gram 滑窗，停用词，MAX_TERMS=24
- `ai/qa/QaScorer`：BM25-lite（k1=1.2 b=0.75，tf cap 4，df 按查询词在候选池统计），多样性惩罚 1/(1+0.5k)
- `ai/qa/QaBudget`：总 8k tokens（system 1600 + 片段 5000 + 历史 1200），MAX_SNIPPETS=12 / per-book 3 / per-chapter 2，片段 500 字，超限先砍历史再砍低分
- `ai/qa/QaPromptBuilder`：system 7 条硬约束 + 片段头 `[n]（来源类型｜《书名》第x章·章名）`；历史回放先剥旧 `[n]` 再截 400 字防多轮引用错乱；每题重新检索重新编号
- `ai/qa/CitationParser`：句切分 → 〔推断〕整句标记 → `\[(\d{1,2})\]` 切分；越界引用按普通文本渲染不吞字
- `ai/qa/QaEngine` + `QaSnippetSource`/`QaAnswerer`/`AiConfigurationSource` 三个可测接口（AppModule 显式 `@Provides` 绑定，项目无 `@Binds`）；未配置 AI 抛 `MISSING_KEY`
- `data/qa/QaSourceLoader`：三层用户数据快照（证据×1.35 / 笔记×1.25 / 节点想法×1.05，各 LIMIT 2000）+ 正文窗口（×1.0）；bodyBookIds = 入口书 + 命中书最多去重 3 本
- `data/qa/BookBodyReader`：parser LRU(2) + Mutex 串行 + `withTimeoutOrNull(6000)` + 60 章上限，窗口前 250/后 350 字；**PDF/CBZ（raster）跳过正文层**，只检索笔记与知识

### 数据与会话
- `ChatSessionEntity`（id/title 首问 24 字/entryBookId 无外键/createdAt/updatedAt/lastMessageAt 排序键）
- `ChatMessageEntity`（sessionId FK CASCADE/role/content/citationsJson/sourceCount/status pending|complete|failed/errorCode/createdAt）；**纯本地、无 syncId**（类注释写明决策）
- `ChatRepository.beginTurn` 同事务写 user 行 + pending 助手行并返回助手行 id；进程死亡后 pending>2min 前端渲染「回答中断」；`sourceCount` 区分「没检索到」与「模型没引用」
- `MIGRATION_22_23` SQL 与实体逐字对齐（`exportSchema=false` 不校验，`ChatMigrationTest` PRAGMA 断言兜底）；citations JSON 用 org.json，含中文引号/换行 round-trip

### UI 与入口
- `ui/knowledge/KnowledgeQaScreen.kt`：顶栏（返回/历史/新建）+ 空态（示例 chips + 未配置 AI 引导 + 隐私提示）+ 消息流（DB Flow 唯一真相）+ Composer + SessionsOverlay
- `KnowledgeQaCitationUi.kt`：`buildAnswerText` 在 AnnotatedString 上 `withAnnotation(CITATION_TAG)`；角标用 `BaselineShift.Superscript` + BasicText/pointerInput/detectTapGestures（照抄 WelcomeScreen 范式）
- 液态玻璃：同 KnowledgeDetailScreen 用 `CompositionLocalProvider(LocalLiquidGlassBackdrop provides null)` 防 P0 自采样崩溃
- 路由 `Screen.KnowledgeQa("qa?bookId={bookId}")`；书详情两处入口 → `MainActivity.EXTRA_OPEN_QA_BOOK_ID` → `requestedQaBookId` → NavGraph LaunchedEffect
- i18n：28 条 `qa_*` × 8 locale（values/en/ja/ko/zh-rCN/zh-rTW/zh-rHK/zh-rMO；HK/MO 逐字一致，TW 用「設定/金鑰/傳送」）
